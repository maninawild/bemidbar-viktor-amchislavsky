# Bemidbar Brand Assets

## Font Source

The Bemidbar wordmark uses Hummus by Andrey Markelov:
https://www.andrewmarcus.ru/projects/fonts/hummus/

The source page states that Hummus is free for any purpose, including commercial use. The bundled file is stored at:

- `public/fonts/hummus/hummus.ttf`
- `public/fonts/hummus/README.md`

## Logo Files

- `public/brand/bemidbar-logo.svg` - default full logo with subtitle.
- `public/brand/bemidbar-logo-dark.svg` - full logo for dark backgrounds.
- `public/brand/bemidbar-logo-light.svg` - full logo for light backgrounds.
- `public/brand/bemidbar-wordmark.svg` - wordmark-only asset.
- `public/brand/bemidbar-og.png` - Open Graph preview image.
- `public/favicon.svg` - browser icon.

## Usage

- Header: wordmark-only asset through `components/bemidbar-logo.tsx`.
- Home hero: full dark-background logo with subtitle.
- Footer: full dark-background logo with subtitle.
- Social preview: `public/brand/bemidbar-og.png`.
- Browser icon: `public/favicon.svg`.

## Rules

Hummus is only for the dedicated Bemidbar wordmark text: `БЕМИДБАР`.

Do not use Hummus for body text, navigation, subtitles, page headings, article titles, buttons, or general decorative headings. Subtitle text in logo assets uses standard serif lettering, not Hummus.
