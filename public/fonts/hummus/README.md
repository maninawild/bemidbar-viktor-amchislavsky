# Hummus Font

Source: https://www.andrewmarcus.ru/projects/fonts/hummus/

Downloaded file: `hummus.ttf`

The source page states, in Russian: "Шрифт Хумус доступен бесплатно для использования в любых целях, включая коммерческие." This means the Hummus font is available free for use for any purpose, including commercial use.

Bundling rule for this project: Hummus is used only for the Bemidbar wordmark text "БЕМИДБАР" inside dedicated logo assets. It must not be used for body text, navigation, or page headings.
